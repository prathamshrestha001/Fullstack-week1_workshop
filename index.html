Study Materials & Tutorials

Module 1: Structuring a Page with HTML

Every web page starts with HTML. In this module you will learn how to use semantic elements to give your page meaning for both people and search engines.

  1. Create the document skeleton with <!DOCTYPE html>
  2. Add a <header>, <nav> and <main>
  3. Group content with <section> and <article>
  4. Finish with an <aside> and <footer>

Module 2: Flexbox and Grid

Flexbox arranges items in one direction; Grid arranges items in rows and columns. Use them together for flexible, modern layouts.

  • Flexbox: navigation bars, card rows, centring content
  • Grid: page layouts, galleries, resource lists
  • Media queries: adapt the design to phones, tablets and desktops

Module 3: Making Pages Interactive

JavaScript lets you respond to clicks, validate forms and update the page without reloading. Start with small projects such as a to-do list or a quiz.

  • Variables, data types and operators
  • Functions and events
  • Selecting and changing elements in the DOM
